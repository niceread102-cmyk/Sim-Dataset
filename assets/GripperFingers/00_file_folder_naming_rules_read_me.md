# 파일·폴더 이름 규칙

처음 보는 사람도 바로 찾을 수 있게 통일했습니다.

## 1. 최상위 폴더: 번호_대상부품_그리퍼종류
- 00_로봇연결_연장어댑터
- 01_로터_파지그리퍼
- 02_캠링_파지그리퍼
- 03_슬리브_파지그리퍼
- 04_서포트_3지그리퍼
- 05_펌프커버_흡착그리퍼
- 06_사이드플레이트_파지그리퍼
- 99_공용_어댑터
- 번호順 = 공정 순서. 00은 로봇 연결 공용, 99는 공용 예비.

## 2. 하위 폴더 5종 고정
- 조립_STEP : 조립된 상태 3D (파지/벌림 상태 확인용)
- 부품_STEP : 낱개 부품 설계용 3D (수정할 때 이거 사용)
- 출력_STL : 3D프린터 출력용 (그대로 출력)
- 도면_PDF : 가공·검사용 도면 (도면_ 접두어)
- 미리보기_이미지 : 열지 않고 보는 사진 (미리보기_ 접두어)

00번 내부(M-20iD용/R-2000iC용)도 동일 규칙입니다.

## 3. 파일 이름: 한글_상태_규격.확장자
- 띄어쓰기 없음, 구분은 _ (언더바)
- 좌/우, 파지/벌림/닫힘, D50/D59, M-20iD/R-2000iC 같은 핵심 검색어는 이름에 유지
- 예: 핑거팁_좌측.step, 조립_파지상태.step, 도면_브라켓.pdf, 미리보기_파지상태.png
- 참고용·간섭확인용은 이름에 용도 표기: 대상부품_슬리브_참고용.stl, 간섭확인용_숄더볼트영역.stl

## 4. 찾기 요령
- 출력할 파일 → 각 폴더의 출력_STL
- 도면 볼 때 → 도면_PDF
- 생김새 먼저 볼 때 → 미리보기_이미지
- 모델 수정할 때 → 부품_STEP 또는 조립_STEP
