그리퍼 단독 / 끝단 직선 버전

압축을 푼 후 jegg2008_straight_300mm.urdf 를 불러오세요.
URDF와 meshes 폴더는 함께 두세요.

- 양쪽 툴 끝의 휘어진 부분을 일자로 수정했습니다.
- 이전 300 mm 연장 유지: 본체 뒤쪽~끝단 약 461.316 mm.
- 로봇 팔은 제외했고, 기존 모터와 8 mm 어댑터는 포함했습니다.
- 단위 m. 추가 0.001 스케일은 필요 없습니다.
- 그리퍼 접근 +Z, 개폐 ±Y (gripper_motor 프레임).
- gripper_left_joint: 0 ~ 0.004 m. 오른쪽은 mimic으로 따릅니다.
- 내부 간격 0 ~ 8 mm. 기존 모델의 스트로크 해석을 유지했습니다.
- TCP: gripper_tcp, 모터 기준 (0, 0, 0.461315849) m.
- 플랜지 기준 TCP: (0.469315849, 0, 0) m.
- 끝단 충돌 형상과 추정 질량·관성을 함께 수정했습니다.

직선 단면, 길이, 대칭 개폐, 메시 경로와 충돌 형상을 확인했습니다.
Isaac Sim 실행과 실제 강성·체결은 미검증이며, 질량·관성은 근사값입니다.
원본 그리퍼 형상: 사용자 제공 jegg2008.stl.
