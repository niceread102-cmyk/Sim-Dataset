# M-20/35-18D + JEGG2008 / 핑거 300 mm 연장

압축을 모두 푼 뒤 **`m20_35_18d_jegg2008_300mm.urdf`** 를 불러오세요.
URDF와 `meshes` 폴더는 같은 폴더에 두어야 합니다. 로봇 메시도 포함되어 있어 별도의 FANUC ROS 패키지를 설치할 필요가 없습니다.

## 반영 내용

- 첨부 `jegg2008.stl`에서 모터 본체, 슬라이더, 양쪽 핑거를 분리했습니다.
- **각 핑거의 직선 구간에 300 mm를 추가**했습니다. 총 길이를 300 mm로 맞춘 것이 아닙니다.
- 모터 크기, 핑거 부착부와 끝의 원래 굽은 모양은 유지했습니다.
- 제공된 로봇 Xacro의 `flange`에 그리퍼를 고정 연결했습니다. `flange`의 바깥 방향인 **+X**와 그리퍼 접근 방향 **+Z**를 맞췄습니다.
- 연결 부위에 지름 80 mm, 두께 8 mm의 간이 어댑터를 넣었습니다. 볼트홀은 모델링하지 않았습니다.
- 양쪽 개폐용 prismatic joint, 끝단 TCP, 질량·관성 및 분할 convex collision을 추가했습니다.
- 원본 STL의 mm 좌표를 m로 변환했습니다. URDF에서 추가로 0.001 배율을 적용하면 안 됩니다.

| 치수 | 값 |
|---|---:|
| 원본 그리퍼 본체 뒤쪽부터 핑거 끝까지 | 161.316 mm |
| 수정 후 본체 뒤쪽부터 핑거 끝까지 | **461.316 mm** |
| 어댑터를 포함한 플랜지 면부터 핑거 끝까지의 축 방향 거리 | **469.316 mm** |
| 커스텀 핑거 자체의 축 방향 길이 | 75.566 → 375.566 mm |

## 조인트와 TCP

| 항목 | 값 |
|---|---|
| 왼쪽 구동 조인트 | `gripper_left_joint` |
| 오른쪽 조인트 | `gripper_right_joint` |
| 두 조인트의 범위 | `0` ~ `0.004` m |
| 핑거 닫힘 | `q = 0` |
| 핑거 중간 | `q = 0.002` m, 내부 간격 4 mm |
| 핑거 최대 열림 | `q = 0.004` m, 내부 간격 8 mm |
| 그리퍼 모터 프레임 | `gripper_motor`: +Z 접근, ±Y 개폐 |
| TCP 프레임 | `gripper_tcp` |
| 모터 프레임 기준 TCP 위치 | `(0.000349988, 0, 0.461315849)` m |
| 플랜지 기준 TCP 위치 | `(0.469315849, 0, -0.000349988)` m |

기본 버전은 `gripper_left_joint` 한 개를 제어하면 `gripper_right_joint`가 같은 변위로 반대 방향으로 움직이도록 정의했습니다. 독립 버전에서는 **두 조인트에 같은 양수 값**을 입력하세요. 축 방향이 반대로 정의되어 있으므로 오른쪽에 음수 값을 주지 않습니다.

## 시뮬레이션 값과 확인 범위

제조사 JEGG-2008 표의 개폐 스트로크 8 mm를 **총 개폐량으로 해석하여 한쪽당 4 mm**로 설정했습니다. 제공 STL의 내부 간격은 7.6 mm였으며 이를 닫힘 기준으로 재배치했습니다. 제조사 표는 한쪽/합산 여부를 명시하지 않으므로 실제 제어기 기준과 대조할 항목입니다. 표의 파지력 14 N와 개폐 속도 65 mm/s도 두 조인트에 절반씩 배분했습니다.

제품 질량 0.23 kg를 본체와 기존 슬라이더에 배분하고, 커스텀 핑거는 철강 밀도 7,850 kg/m³로 추정했습니다. 어댑터는 알루미늄 밀도 2,700 kg/m³로 추정했습니다. 추가 부품의 무게중심·관성은 단순 근사이며 실제 측정값이 아닙니다. 로봇 관절의 원래 위치·축·범위·질량·관성은 제공 Xacro의 값을 유지했습니다.

XML 및 단일 연결 트리, 모든 메시 참조 경로, 단위·길이, 질량·관성의 양수 조건, 플랜지 장착 방향, 0/4/8 mm 대칭 개폐, 충돌 메시의 폐곡면·convex 상태를 확인했습니다. 원본 시각 메시의 일부 열린 모서리는 외관에 남아 있으며, 충돌에는 별도의 닫힌 메시를 사용합니다.

**Isaac Sim에서 실제 import/실행은 검증하지 않았습니다.** 강체 시뮬레이션용 모델이며 300 mm 연장에 따른 실제 핑거 처짐, 모터 허용 모멘트, 체결 볼트 배치는 검증하지 않았습니다.
